# Shipbraid brand assets

The primary mark is [shipbraid-logo.png](shipbraid-logo.png), a transparent PNG for repository pages, presentations, and application branding. Both project READMEs use this same file. This is a raster asset, not a vector source.

[shipbraid-preview.png](shipbraid-preview.png) is a browser-rendered light/dark presentation of the mark, name, and tagline. Use the transparent primary mark for integration.

## Design

Interwoven ribbons form an S-shaped braid. Their crossings represent independent release requests sharing work and handing execution over safely. The open gaps preserve each strand's identity, just as a request keeps its identity when its run is replaced.

- Project name: **Shipbraid** (capital S, lowercase b).
- English tagline: **Shared runs. Safe handoffs. Verified releases.**
- Chinese tagline: **共享执行，安全接棒，验收交付。**
- Intended palette: teal `#087F8C` and amber `#E6A23C`.
- Keep the original aspect ratio and transparent background; leave clear space around the mark. Keep the project name as selectable text alongside it.

The palette values are design targets for generated raster artwork, not a guarantee that every antialiased pixel has one of these exact values.
